# What the second edit teaches us

This round keeps the agreed meaning: the object is the trace of a connected transformation, with context-dependent contributions through many weights. It is not a collection of individually meaningful scalars. [Full results](../studies/03-round-1-single-pair-edits/B-selective-footprint/run/REPORT.md).

The first edit repaired two numerical chains and damaged a different verdict. We followed four important outcomes with native captures. Then we changed the input direction of the actual stored matrix update to reduce its response near the damaged continuation's branch.

That reduced response survived BF16 rounding approximately, and the damaged final triple returned to its original value. The intended target repair also disappeared. A and B have similar effects at the single input used to design the repair, but different effects as the response proceeds. One fresh disc calculation improved under B, recorded separately from the failed selective prediction.

The immediate lesson is about continuity across contexts: matching one anchor did not retain the desired development of the correction. A proposed next edit should ask what must be preserved across several connected observations, not simply how to make one point closer to a donor. This is a new experimental question, not a claim that an entire capability has been recovered or that a later edit is already safe.

These results keep the earlier partial-trace signal and add a measured tradeoff. They do not prove the wider geometric account: the line plot of vector changes is an observation aid, not that hidden geometry itself.
