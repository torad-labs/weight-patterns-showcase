# The selected reference and one wrong computation remain the experiment

Marcos corrected the implementation peer on November17,2026 (CT), while asking for the four research documents to remain the baseline. This records the understood scope and the implementation peer's own interpretation error; it is not a new method or enforcement rule.

The first training experiment was deliberately narrowed to the most-correct available reference and one incorrect answer. Training all30 together had been unstable and unproven. The reference is fixed; the incorrect prompt is regenerated from the newly edited model after each update, and its computational divergence is measured again. Other answers categorized as correct can contain incorrect intermediate computation. They are not all fully correct labels or simultaneous training targets.

The implementation peer had the one-pair scope in the source notes but let the broader many-trace hypothesis displace it when interpreting the review. Reporting that all14 nonself outcome-successful witnesses have positive loss, with five above the original wrong trace, is numerically accurate. Treating this as evidence that the agreed one-pair objective is wrong was not justified. That inference is withdrawn. The data do not justify switching references, bringing all those answers into training or expanding tolerance until they fit. They also do not prove that every penalized witness cell is erroneous; that attribution was not established.

The current code audit still distinguishes actual questions about correspondence, tolerance behavior, computational-to-weight derivatives, trainable scope and native response fidelity. These are investigated against the selected pair and actual update path. The reference-distance score is the declared experimental measure; neither whole-hypothesis validation nor a universal cross-answer correctness ranking is a prerequisite substituted for this experiment. Exact zero and exact restoration are not required endpoints under Marcos's November16 learning-goal clarification.
