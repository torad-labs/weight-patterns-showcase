## Intent and consequence

The object to compare is what each layer or merge does to its own input: the
relation between incoming and outgoing computation. Bringing residual values toward
other answers' residual values can carry their content. Normalizing those values or
placing them in a convex hull does not by itself turn state matching into a comparison
of the transformation. The trace remains the loss and is measured again after every
update; output words or answer values are not read as the judge.

The running successful-set construction measures post-merge unit state and log size
against successful post-merge states. Its correspondence uses turns, but its loss
does not measure the input-output relation. Astra specified and admitted that loss;
this is a mismatch in Astra's construction, not a failure of the research hypothesis
or a numerical verdict from an unfinished sweep.
