# Studies Overview (`01`–`05`)

This directory preserves the chronological experimental arc of the repository—from early weight-space orientation and quantization calibration through native BF16 residual-stream tracing, analytical single-pair weight edits (`A`–`D1`), multi-trace cohort overlap, and iterative direct computational-trace backpropagation. All negative results, falsified intermediate constructions, and provenance chains remain intact alongside positive repairs.

For the narrative synthesis across phases, see [../../JOURNEY.md](../JOURNEY.md). For Round 2's active status log and structured 226-run index, see [04-round-2-overlap/ROUND-2.md](04-round-2-overlap/ROUND-2.md) and [04-round-2-overlap/RUN-CATALOG.md](04-round-2-overlap/RUN-CATALOG.md).
