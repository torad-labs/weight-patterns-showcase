# Study Phase 03: Round 1 Single-Pair Weight Edits (`A` → `D1`)

Executed November 7, 2026 on native **Gemma 4 E2B BF16** (`google_gemma-4-E2B-it-bf16.gguf`, `9,311,304,896` bytes, greedy decoding on RTX 5080), Round 1 tests a four-step analytical weight-editing ladder (`A → B → C → D1`) inside a single attention output matrix (`blk.16.attn_output.weight`, `1,536 × 2,048` = `3,145,728` BF16 parameters), without gradient training or runtime activation hooks.

Whereas a one-step activation swap at layer 16 ([Phase 02](../02-physics-trace-observation/physics-intervention/STUDY.md)) vanished on the very next token, writing the derived rank-one update into native BF16 weights re-applies the modified transformation at every token—repairing the targeted physical reasoning chain and transferring to a second sled problem, while exposing a crisp progression of mechanistic failure modes and analytical remedies.

## Why Phase 03 Motivated Phase 04 (Round 2)

`D1` proved that an analytical BF16 weight edit derived from internal computation can repair specific multi-step reasoning trajectories, survive native quantization rounding, and avoid general-text side effects—but **constructing an edit from a single prompt pair at a single chosen matrix (`blk.16.attn_output`) did not generalize across diverse physical problem formulations (`1/4` fresh physics)**. [Phase 04 (Round 2)](../04-round-2-overlap/RUN-CATALOG.md) removes both bottlenecks by overlapping whole cohorts (`30` correct vs. `30` downhill-sign failures) across all `35` layers (`105` merges) and differentiating computational discrepancy directly into all participating weights.
