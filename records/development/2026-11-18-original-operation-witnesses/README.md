# Original operation witnesses

The manifest binds all 30 exact prompt cases, natural responses, complete prompt and decode turns, raw decode endpoint norms, and the independent downhill and friction landmarks in one native event space. It uses the published original-model cohort. Fifteen answers correctly applied downhill work and fifteen did not. All 30 correctly subtracted friction conditional on the energy that reached that step. One response reached its generation cap. Witness manifest · [Prior independent operation annotations](../../../studies/04-round-2-overlap/runs/descent-operand-identity/annotations/events.json) · Earlier availability and provenance review

The question and decode arrays cover 5,159 and 14,592 events respectively, each with 105 merges and 1,536 coordinates. The first decoded prediction uses the prompt's final consumed input, which appears only in the decode half. Event zero is the first consumed input. The audited downhill and friction events already use that full coordinate system. A reader of just the decode arrays subtracts the case's `prompt_events`. Source result hashes, exact case IDs, prompt-token counts, original reading membership, natural emission positions, every case's native exporter dimensions, and bounds of all audited events were checked. Array payload hashes come from the original manifests. Executable loader

Use `open_manifest()` to read the binding, `open_member(member)` to open the two turn matrices and decode norms with read-only NumPy memory maps, and `full_turns(opened)` to concatenate one member's native path. The CLI `--verify-blobs` also verifies every array's SHA-256. The two native norm channels are `[L2(incoming), L2(merged)]` in float64, before unit normalization, at each decode event and merge. Prompt endpoint norms and native endpoint vectors remain in the separately restorable raw state and input records. The turns alone do not recover them. Original native state archive
