# Final Experiment research record

The research target is a reproducible weight-training procedure for a recurring divergence in model computation. Earlier interventions already transferred. The method under development registers freely generated executions by their internal transformations, compares them with fixed successful computation, measures each excess above local correct-to-correct variation, pulls those errors through shared weights, installs the update and reacquires the trace. A change of physical operation does not select a different updater. Human audits describe which parts of an answer changed. The weight transplant is a controlled intervention for understanding the learner. [Executed method](../FINAL-EXPERIMENT.md) · [Matched whole-trace comparison](../studies/04-round-2-overlap/runs/frozen-energy-paired-overlap/declaration.json).
