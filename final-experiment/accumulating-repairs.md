# Can a second weight edit preserve the first repair?

November 18, 2026. This is a prospective diagnostic alongside the single trace learner. The primary training algorithm takes local discrepancies from the computational overlap and differentiates the same objective for every case. The transplantation arms test how earlier measured weight changes interact. Its unit of success is **one model that freely performs both required operations on the same eligible question**. In the observed one-pair learner, the 115 J development problem acquired the correct 30 J climb requirement, yet continued to subtract 30 J of downhill work from 96 J. The 91 J fitting case acquired the correct descent on the same checkpoints. The proposed experiment asks whether a stored change accounting for downhill repair can be added on a background where another repair already works. Case-by-case evidence and historical examples

## 2. Distinguish transfer from repetition on related weights

The 175 checkpoint restored T and applied one further training update. Its already-correct fitted descent and still-incorrect 115 J development descent make it informative for measuring **dose or reversion on a descendant**. Neither reinstalling T's tensors nor adding its full historical difference to 175 introduces an independently learned capability. 175 parent checkpoint · [175 and 189 endpoint identities](../records/development/2026-11-17-family-swap/families.json)

For a receiving model $B$, construct a fresh private copy for each arm. Use the model’s actual native rounding $Q$ only at the stated installation boundary. Freeze the receiver, donor and family before observing edited answers. Outside the selected family all stored bytes must match B. Record the following actual displacements over native coordinates.

| Arm | Stored selected weights | What the control distinguishes |
| --- | --- | --- |
| B and identity installation | $B_F$ and $Q(B_F+0D_F)$ | Same starting behavior and preservation of native bytes in the installation path. |
| Donor difference | $Q(B_F+\alpha D_F)$ | Tests the effect of the donor’s historical change on B while retaining B's adaptations there up to native rounding. |
| Donor endpoint replacement | $T_F$ in full | Tests donor family state. Its actual shift is $T_F-B_F$, which may undo the recipient's own learned changes. Include both any B-only sparse coordinates and unchanged donor coordinates. |
| Historical reconstruction | $Q(E_F+D_F)$ on E, and $T_F$ on T | At unit dose the former must reconstruct the donor family bytes. Reinstalling T on T must change zero bytes at all coordinates. |
| Repeated donor difference | $Q(T_F+D_F)$ on T | This is a second dose relative to E. It can move a model whose descent is already repaired. A favorable or harmful result belongs to dose sensitivity. |

When B is 175, $B=T+U$ in decoded native coordinates. The additive arm is consequently $Q(T_F+U_F+\alpha D_F)$. Endpoint replacement removes $U_F$ on the selected family. Check and report equality of realized bytes between arms, including zero and duplicate perturbations, before spending an additional generation. With the two disjoint donor families on E, the joint unit transplant reconstructs T if all remaining tensor bytes also agree. Do not use an unrelated seed to interpret sparse override files.

## 4. Freeze the interventions before evaluating behavior

For the primary comparison evaluate **the original, original plus $D_F$, FK, and FK plus $D_F$** for each donor family at its measured unit dose. The common original and FK controls are acquired once under the same conditions. This comparison isolates the effect of the signed downhill edit with and without the earlier climb edit. At the native install, the coordinate perturbations on the two backgrounds can differ because of rounding. Record them on each background. Keep donor endpoint overwrites and repeated doses as separately labeled controls. The original-vs-FK comparison establishes that the first edit earned the prior repair; the FK-vs-combined comparison establishes whether it survived while downhill changed. Report the complementary original-plus-donor result even if it solves the entire problem unaided. A net increase in total complete answers can occur while losing the first repair on the intended case.

The attention-output arm leaves all three FK tensors byte-identical. For down-projection, also evaluate a protected variant with the layer-11 donor change masked out. Keep the full down-family result as its control. Record the actual post-rounding displacement and hash each of the three protected tensor byte ranges. An unchanged tensor can receive a different activation from an edited upstream computation, so both variants still require free generation.

Unit dose means the actually observed donor displacement $D_F$. Zero dose is the identity. Those two levels determine the primary experiment without a tunable strength. If a secondary recipient-specific scale is wanted, predetermine its construction using only declared design recordings and freeze it before observing any new generated answers. For example, on B’s fixed calibration histories stack the local weighted residuals $r$ and compute $q=J_r D_F$ under the established graph. The nonnegative least-squares line scale is $\max(0,-r^\mathsf{T}q/\|q\|^2)$ when the tangent is nonzero. Define beforehand how to aggregate eligible downhill requests, which correctly performing operations must remain within their measured tolerance, and what to report for an undefined, conflicting or infeasible solution. Use no held measurements to choose the scale. For any proposed scale form $u_B=Q(B+\alpha D_F)-B$. Store changed entries, per-tensor norms, alignment with $D_F$, the exact native payload hash and $J_r u_B$. A proposed scale that rounds to zero, duplicates unit dose, or violates the declared preservation limits supplies that result. Scaling a historical difference is a local approximation, especially on an independent recipient. Do not select a second dose because the first generated answer missed.

## 5. Read conflict at three different levels

1. **Stored coordinates.** Report support intersection, signed inner product and norm by tensor on the common coordinate system. FK affects `blk.11.ffn_down.weight` and the layer-14 K/V matrices. Its only possible directly shared tensor with the down-family donor is layer 11. Its direct tensor support does not intersect that of the attention-output donor. Disjoint coefficients can still interact through changed activations or attention state. A weight displacement across 174 steps is distinct from a current loss gradient.
2. **Local sensitivity.** At the receiver’s fixed history, the local derivative $g_k=J_k^\mathsf{T}r_k$ (up to the loss's constant factor) and $g_k^\mathsf{T}u_B$ predict the sign of first-order change in a divergent cell’s squared residual. For an already-correct operation inside tolerance the local loss gradient can vanish. Measure its **trace** Jacobian $J_{z_k}u_B$ and remaining margin to the tolerated region as well. When computing new parameter gradients for both objectives, measure their inner product at the same receiver, using the same parameter metric and stated local losses. A negative inner product predicts first-order disagreement between their descent directions there. Evaluate each actual installed displacement on both named operations at matched stages. Save the local components. An aggregate can conceal opposing signs.
3. **Executed computation.** Compare native fixed-prefix effects with the predictions where retained inputs agree. Then regenerate each case freely, reacquire the trace, preserve multiple divergent regions and mark stage ambiguity. A changed decoded history can redirect both computations. A good linear forecast conditional on the previous prefix is insufficient evidence of a combined behavioral repair. ## 6. Declare what counts as an accumulated repair

Use the known fitted, reference, 115 J, reordered and historical FK cases for reconstruction and development only. Run every predeclared arm from its own fresh model on the **same** held prompts. Freeze the arithmetic evaluator, rule for matching operations, scale, source hashes and decoding settings before opening edited outcomes. Partition by underlying physical configuration. Vary prompt order within each configuration, retain original successes and eligible failures, and report families that lack either case type. A separate new cohort is needed for any claim that a method chosen from this comparison transfers again. The sealed cohort is not required.

For each question, retain the pre-edit and post-edit arithmetic, the specific earlier repair, the target descent, friction on the input it received, final physical energies and verdict, and any new error or omitted computation. The key denominator is original eligible cases where the first intervention repaired an identified operation and the receiver still gets the second operation wrong. Count both-correct on the *same* natural generation, reversions of the first repair, persistent target errors, new errors elsewhere and incomplete generations. Show target-only and preservation controls as separate denominators. A correct YES obtained from wrong energy is still a downhill failure. If no eligible cases occur, the comparison has provided no estimate for accumulated repair. Failure of both candidate transplants on held cases would identify a transfer limit for these specific directions. A completed fitted repair, a lower trace loss, or combining successes from two different questions cannot replace the held joint outcome. ## 7. Follow-up diagnostic if the transplant interferes

Interference has an observable meaning here. The combined model must lose a previously verified operation that FK still gets right on the same case, or lose a downhill repair the donor alone achieves there. An edit that has no effect on downhill in either background gives no evidence for conflict. Qualify each operation from the generated calculation and its trace. Cases that reveal interference become development evidence for this follow-up.

This diagnostic can ask what a supervised intervention would recover after a conflict. Its hand-registered operations exclude it from the reusable training recipe. Start the follow-up from a clean copy of FK. For each supervised downhill region, use the fixed, independently correct downhill trace as the target. For each protected region, freeze the trace of a valid climb or friction operation from the recipient before the new edit. Match by computation. Local discrepancies at divergence onset, peak and return each contribute their own gradient. Preserve variation across verified correct traces through the measured tolerance. A trace inside that range incurs zero preservation loss. Keep the FK coefficients themselves fixed in the protected-weight arm and report exactly which donor changes survive this mask.

One concrete joint update minimizes downhill trace loss subject to keeping each protected trace inside its calibrated range. On the current model, compute the downhill weight gradient by pulling each local trace derivative back through its executed layers. For a proposed step, also compute the predicted displacement of each protected trace, including traces whose current loss is zero. If the downhill step crosses a boundary, solve for a step that reduces downhill error while respecting those margins. A zero displacement always preserves a feasible starting point. Before fitting, bind the minimum detectable downhill improvement to repeated-measurement variability, and the allowed step radius to observed local response on development histories. Report whether an improving native step was found within that radius and the protected margins. If only the linear constraints were solved, state that explicitly. A failed search at one radius leaves global compatibility open. A low mean loss can hide an individual climb regression.

Install the native rounded step, regenerate from the updated model, and measure both operations again. Compare this procedure with downhill-only training from the same checkpoint and evaluation budget. Freeze the development stopping rule before acquiring a new evaluation panel. Report successful joint repairs, losses of either operation, unchanged failures and ambiguous traces on that fresh panel. A failed transplant followed by successful joint training would distinguish the portable training procedure from the particular stored weight change.
