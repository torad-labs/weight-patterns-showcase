## Actual checkpoint change

The external llama.cpp research arm used native **BF16**, separate from the earlier mixed Q4_K checkpoint and from production QGRE. Matrix `blk.16.attn_output.weight` has 2,048 inputs and 1,536 outputs. The editor read all **3,145,728** entries and rounded the candidate into native BF16 before ordinary inference used it.

| Measurement | Result |
| --- | ---: |
| Changed stored values | 200,965 / 3,145,728 |
| Changed bytes | 204,565 |
| Realized update norm / original matrix norm | 0.029656% |
| Remaining raw-output distance to paired successful source at the captured input | 44.4103% |
| Corresponding reduction in that distance | 55.5897% |
| Bytes compared across complete checkpoint files | 9,311,304,896 |
| Changed bytes outside the selected matrix | 0 |

The 55.5897% is a **projection-distance reduction at one recorded input**, not a percentage of recovered physics, whole-trace alignment, or model accuracy. The candidate was `ΔW = (y_success − y_failure) x_failureᵀ / ||x_failure||²`, followed by native BF16 rounding. The source difference includes the prompts' different climb heights.

| Case | Original available / required / verdict | Edited |
| --- | --- | --- |
| Target: 3 kg block, 3 m climb | 60 / 120 / NO | **60 / 90 / NO** |
| Paired 3 kg block, 1 m climb | 60 / 30 / YES | Identical, 450 tokens |
| Sled, 1 m climb | 0 / 40 / NO | **80 / 40 / YES** |
| 4 kg block, 2 m climb | 60 / 80 / NO | **60 / 40 / YES — regression** |

All six supplied-arithmetic continuations were identical. All seven formerly correct numerical chains stayed correct. Eighteen of 28 full continuations were identical; nine of 28 hit the token cap in each arm. A correct numeric triple does not establish a fully correct explanation.

The native capture matched ordinary edited inference on **3,396 decisions**. Paired internal analysis covered the two source cases. On identical histories, **19,152 retained upstream checks** were unchanged, while the edited projection and downstream states changed. At prediction 235, relative differences were 0 at the input, 0.9191% at the projection output, 1.0273% at its normalized contribution, 0.3570% at layer 16 exit, 0.02357% at layer 34 exit, and 0.05797% at final normalization. Each percentage has its own boundary vector denominator.

The repaired response first diverged at prediction **269**: ` reached` was preferred before, ` gained` after. The edited continuation computed the recipient's own 90 J climb requirement. This is a visible text branch following a persistent intervention, not a word-level causal isolation. Across the full suite, every one of the **11,053 comparable complete-score hashes** changed, even when selected tokens did not.

The context-length analysis reported 2.725 ms additional decode latency per 1,000 context tokens, with R² 0.999525; a separate diagnostic tail gave 2.730. ## What can be said now

We observed recurring partial connected computation on capability-focused cases. A subsequent persistent parameter edit in the investigated region moved a recorded contribution toward its paired successful source, propagated through ordinary inference, and repaired two numerical chains while damaging a different verdict. That is useful evidence for pursuing this research direction.

The experiment does not establish a complete physics representation, exclusive capability attribution, general edit safety, or the causal necessity of the FF14/FF15 statistic for the later repair. There was no unrelated-language benchmark or matched-size random-edit comparison. These are boundaries of the claims, not retroactive demands that erase the partial result.
